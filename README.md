# Bone Mining Notifier

A RuneLite plugin that notifies you about calcified rocks while bone mining in Varlamore.

## Notifications

- **Depletion** — a calcified rock depletes directly adjacent to you (cardinal directions only — north, south, east, or west), so you can move to the next rock without losing ticks.
- **Respawn** — the depleted calcified rock you are standing next to and facing becomes minable again, so you can start mining as soon as it's back.

Each notification has its own setting and can be configured or turned off independently.

## Configuration

| Setting | Description |
|---|---|
| **Bone mining notification** | How you are notified when an adjacent calcified rock depletes (tray popup, screen flash, sound, etc.) |
| **Rock respawn notification** | How you are notified when the calcified rock you are facing respawns |
