# Bone Mining Notifier

A RuneLite plugin that notifies you when a calcified rock depletes directly adjacent to you (cardinal directions only — north, south, east, or west).

Useful when mining calcified rocks in Varlamore, where quickly reacting to a depletion lets you move to the next rock without losing ticks.

## Configuration

| Setting | Description |
|---|---|
| **Bone mining notification** | Configure how you are notified (tray popup, screen flash, sound, etc.) |
